# NovelReader

一个原生 macOS TXT 小说阅读器。打开本地小说即可阅读，支持自动识别章节、选择跳转、调整字号和配色，以及退出后恢复阅读位置。完全离线，无账号、广告、网络请求或第三方依赖。

> 目前仓库提供源码，尚未发布可直接下载安装的 `.app` 或 `.dmg`。首次使用需要先在自己的 Mac 上构建应用，步骤见下方。仓库名为 **NoveReader**，应用和工程名为 **NovelReader**。

## 使用要求

| 项目 | 要求 |
| --- | --- |
| 电脑 | Apple Silicon Mac，即 M 系列芯片；当前构建不提供 Intel 版本 |
| 系统 | 最低部署目标为 macOS 14；macOS 14 实机兼容性仍待验证 |
| 小说文件 | 本地 `.txt` 文件，不支持 EPUB、MOBI、PDF |
| 构建工具 | 完整 Xcode 16 或更新版本；已有指定 SDK 的用户也可使用命令行脚本 |

源码使用 Swift 6 和 Xcode 16 的目录同步工程格式。应用构建后，日常阅读不需要启动 Xcode，也不需要联网。

## 获取和启动应用

### 第一步：下载源码

不熟悉 Git 的用户，可以在 [仓库首页](https://github.com/ARainyNight/NoveReader) 点击绿色 **Code** → **Download ZIP**，双击解压下载的 ZIP 文件，再打开解压后的文件夹。

使用 Git 的用户，在「终端」执行：

```sh
git clone https://github.com/ARainyNight/NoveReader.git
cd NoveReader
```

下载源码后还不能直接阅读，需要完成下面的构建步骤。`build` 是本机构建输出目录，不包含在源码下载包中。

### 第二步：构建应用

**方式一：使用完整 Xcode**

1. 安装 [Apple Xcode](https://developer.apple.com/xcode/) 。仅安装 Command Line Tools 不会提供 Xcode 图形界面。
2. 在源码文件夹中双击 `NovelReader.xcodeproj`，使用 Xcode 打开。
3. 在顶部运行配置选择 `NovelReader`，运行目标选择 `My Mac`。
4. 点击左上角运行按钮，或按 `⌘R`，等待编译完成并弹出阅读窗口。
5. 如需以后独立启动，在 Xcode 菜单选择 **Product** → **Show Build Folder in Finder**，进入 `Products/Debug`，找到 `NovelReader.app`，复制到「应用程序」文件夹。以后可从「应用程序」或 Spotlight 打开。

工程默认使用本地 ad-hoc 签名，不需要配置用于对外分发的签名证书。完整 Xcode 的构建流程尚未在维护者环境中验收；已验证的是下面的命令行脚本构建，具体环境记录见 [ROADMAP.md](ROADMAP.md) 。

**方式二：使用命令行脚本**

当前 `scripts/build.sh` 和 `scripts/test.sh` 明确指定 **macOS 26.5 SDK**，并生成 Apple Silicon 应用。它们不是适用于任意 SDK 版本的通用脚本。

在「终端」进入下载的源码文件夹后，先检查所需 SDK 是否存在。如果通过 ZIP 下载，可以在终端输入 `cd` 和一个空格，将解压后的源码文件夹从访达拖入终端，再按回车，即可进入该目录。

```sh
xcrun --sdk macosx26.5 --show-sdk-path
```

如果命令返回 SDK 路径，再执行：

```sh
zsh scripts/build.sh
open build/NovelReader.app
```

成功后会显示 `Built: …/build/NovelReader.app`，应用位于源码文件夹的 `build/NovelReader.app`。可在访达中将它复制到「应用程序」，以后直接双击启动。

如果提示找不到 `macosx26.5`，当前工具链无法直接使用这两个脚本。请使用完整 Xcode 的工程构建方式；不要将安装任意版本的 Command Line Tools 当作已经具备所需 SDK。

### 第三步：打开第一本小说

1. 启动 `NovelReader.app`。
2. 首次启动会显示「打开小说」，点击后选择本地 `.txt` 文件。也可以按 `⌘O` 打开文件选择器。
3. 等待文件打开，使用鼠标滚轮或触控板上下滚动阅读。大文件还需要等待后台章节解析完成。
4. 将鼠标移到阅读窗口顶部，显示操作按钮。平时按钮会自动隐藏，让正文占据阅读区域。
5. 读完按 `⌘Q` 退出；下次启动会尝试重新打开上次小说并恢复阅读位置。

本版通过应用内文件选择器打开小说；访达中双击 TXT、拖入窗口不是当前提供的打开方式。

## 日常操作

### 顶部按钮

将鼠标移到窗口顶部，按钮从左到右分别是：

| 按钮 | 用法 |
| --- | --- |
| 文件夹 | 打开另一本本地 TXT 小说 |
| 章节列表 | 打开章节目录，点击标题跳转；选择后自动收起 |
| 小字号／大字号 | 每次减小／增大 2pt，范围 12～40pt，默认 20pt |
| 月亮／太阳 | 切换深色／浅色主题 |
| 调色板 | 打开外观设置，修改字体颜色、背景颜色和窗口边框 |

也可使用屏幕顶部的「阅读」菜单，无需一直显示窗口内按钮。

### 章节跳转

点击章节列表按钮，或按 `⌘⇧T`，也可选择菜单「阅读」→「选择章节…」。在弹出的目录内上下滚动，点击要读的章节即可跳转，按 `Esc` 可关闭目录。

章节在打开小说时按本地规则识别，不调用在线 AI，也不修改原文。支持的独立标题行包括：

```text
第一卷 风起
第一章 初入江湖
第002章：归来
第三回再会
第十二节 夜行
序章
番外 二：重逢
尾声
Chapter 1 — Home
Chapter V
```

中文编号支持阿拉伯数字、全角数字及常见中文数字。标题前可以有空格或缩进，中文章节名可以紧接编号。解析会结合标题长度、编号格式和正文标点过滤内容，因此无法保证识别任意写法；没有明显章节标记、过长或含复杂正文标点的标题可能漏识别。没有结果时，目录会显示「未识别到章节标题」，仍可正常滚动阅读。

选择章节会保存阅读进度。只要所选标题仍在屏幕内，优先以该标题恢复；继续滚动离开标题后，按当前阅读位置保存。

### 配色和屏幕取色

1. 点击调色板按钮，或选择「阅读」→「外观设置…」。
2. 点击「字体颜色」或「背景颜色」旁的色块，使用系统颜色面板选择颜色。
3. 想使用屏幕上已有的颜色，点击对应吸管按钮，再点击屏幕上的目标颜色。按 `Esc` 取消本次取色。

字体颜色和背景颜色分别设置并保存在本机。切换浅色／深色主题会清除自定义配色，恢复该主题的预设颜色。这里的「字体颜色」用于改变文字颜色，不提供字体家族选择。

### 窗口大小、边框和全屏

- **移动窗口**：按住窗口顶部留白拖动。
- **调整大小**：拖动窗口四边或四角。正文左右各留 12pt，随窗口宽度铺满，保留原文段落缩进。
- **隐藏／恢复边框与阴影**：按 `⌘⇧B`，或在「阅读」菜单／外观设置中切换「隐藏窗口边框与阴影」。隐藏后仍可通过顶部移动、边缘缩放。
- **进入／退出全屏**：按 `⌃⌘F`，或选择「窗口」→「进入／退出全屏」。
- **重新显示已关闭的阅读窗口**：点击 Dock 中的应用图标，或选择「窗口」→「显示阅读窗口」。关闭窗口与退出应用是两种操作；退出请按 `⌘Q`。

### 快捷键速查

`⌘` 为 Command，`⇧` 为 Shift，`⌃` 为 Control。

| 快捷键 | 操作 |
| --- | --- |
| `⌘O` | 打开小说 |
| `⌘⇧T` | 打开章节目录 |
| `⌘＋` | 增大字号；常见键盘需同时按 Shift 输入加号 |
| `⌘−` | 减小字号 |
| `⌘⇧B` | 显示／隐藏窗口边框与阴影 |
| `⌃⌘F` | 进入／退出全屏 |
| `Esc` | 关闭章节弹窗，或取消正在进行的屏幕取色 |
| `⌘Q` | 保存进度并退出应用 |

## 自动保存与隐私

应用自动保存每个文件的阅读位置、最近打开的文件、字号、主题、自定义配色、边框开关，以及窗口大小和位置。切换小说和退出时会保存阅读进度，无需手动操作。

重启恢复以让上次阅读处重新出现在屏幕内为目标，允许约一屏的向前回看误差。原文件不存在时回到打开页面；文件访问授权失效时，需要重新选择文件。应用不是书架，切换文件仍通过「打开小说」完成。

小说由本地原文件只读加载，不会被上传或修改。偏好和阅读进度保存在应用沙箱的本机 `UserDefaults`；最近文件通过 macOS 安全作用域书签访问。应用没有联网权限、账号系统或同步功能。

## 常见问题

**下载 ZIP 后找不到应用，怎么办？**

ZIP 中是源码，不是安装包。请先按「获取和启动应用」完成构建。当前没有 Release 安装包，也没有 Homebrew 安装方式。

**构建脚本提示找不到 macOS 26.5 SDK？**

脚本固定使用该版本 SDK，需让当前工具链提供它。没有该 SDK 时请使用完整 Xcode 打开工程构建。完整 Xcode 路径尚未验收，遇到问题可附上 Xcode 版本和完整报错提交 Issue。

**打开小说乱码，或提示无法识别编码？**

支持 UTF-8、带 BOM 的 UTF-16 LE／BE、GBK／GB18030；无 BOM 的 UTF-16 使用启发式检测，存在歧义。可用文本编辑器将文件另存为 UTF-8，再重新打开。仅将文件扩展名改成 `.txt` 不会转换格式或编码。

**为什么没有章节，或有些章节不在目录里？**

请检查标题是否独占一行，并具有上述可识别的编号或序章／尾声等标记。纯标题、不规则格式、过长或含复杂标点的标题可能漏识别。目录不支持手工添加章节，未识别的内容仍在正文中，可以滚动阅读。

**看不到顶部按钮，或隐藏边框后不知道怎么操作？**

将鼠标移到窗口顶部即可显示按钮，也可以通过屏幕顶部的「阅读」「窗口」菜单操作。按 `⌘⇧B` 可恢复边框，顶部留白可拖动窗口。

**阅读位置没有恢复？**

先确认原 TXT 文件仍然存在且能够访问；授权失效时重新选择它。应用按文件分别保存位置，以另一份复制文件打开时可能被视为新的文件。恢复存在约一屏的向前回看误差。

**支持 Windows、Intel Mac、EPUB 或在线书源吗？**

当前只提供 Apple Silicon macOS TXT 阅读器。不提供 Windows／Intel 构建、其他电子书格式、在线书源、书架、正文搜索、手动书签或同步功能。

## 开发与验证

SwiftUI 管理界面，AppKit／TextKit 2 提供单个 `NSTextView` 的正文排版与原生滚动。文件读取和章节解析在后台执行，阅读位置使用 UTF-16 文本偏移量。

| 目录 | 内容 |
| --- | --- |
| `NovelReader/App` | 应用入口和菜单 |
| `NovelReader/Views` | 阅读页面、章节列表和外观设置 |
| `NovelReader/Reader` | TextKit 阅读、定位和进度协调 |
| `NovelReader/Services` | 文件解码、章节解析和本地存储 |
| `NovelReader/Models` | 阅读状态和章节模型 |
| `NovelReader/Utilities` | 原生窗口配置 |
| `NovelReaderTests` | 功能回归和大文件性能测试 |
| `scripts` | 本机构建与验证脚本 |

具备脚本所需的 macOS 26.5 SDK 后，在仓库根目录执行：

```sh
zsh scripts/test.sh
zsh scripts/test.sh --benchmark 10
build/NovelReaderTests --benchmark 50
build/NovelReaderTests --benchmark 100
```

测试覆盖编码、偏好与进度持久化、文件重开、章节识别与跳转、TextKit 2、窗口缩放和阅读恢复。性能测试会生成 10／50／100MiB 的中文 TXT，产物和报告位于被 Git 忽略的 `build` 目录。性能报告列依次为文件大小、后台读取、后台解析、标题数、正文装载、80％位置恢复、最长滚动调用、字号修改和峰值内存。

已在维护者的 Apple Silicon 环境中通过脚本构建、回归测试和实际应用验证；完整 Xcode 构建及最低系统实机兼容性仍待验证。最新进度、测试环境和性能数据见 [ROADMAP.md](ROADMAP.md) 。

遇到问题，可在 [Issues](https://github.com/ARainyNight/NoveReader/issues) 提供系统版本、芯片型号、构建方式、复现步骤和报错信息。涉及小说内容时，可提供最小的虚构 TXT 样本复现。
