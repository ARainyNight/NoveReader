# NovelReader

面向 Apple Silicon 的原生 macOS TXT 小说阅读器，最低系统版本 macOS 14。SwiftUI 管理页面，AppKit／TextKit 2 提供正文排版与原生滚动。应用完全离线，无账号、网络请求和第三方依赖。

## 使用

首次启动点击中央的「打开小说」，选择本地 `.txt` 文件。支持 UTF-8、带 BOM 的 UTF-16 LE／BE、GBK／GB18030；无 BOM 的 UTF-16 使用字节特征检测，无法可靠识别时建议另存为 UTF-8。

- 鼠标滚轮或触控板上下滚动阅读。
- 鼠标移到窗口顶部显示控制区，可打开其他小说、调整字号、切换主题及打开「外观设置」；移出后隐藏。
- 按住顶部留白拖动窗口，拖动四边或四角调整大小；不再限制为至少 440×320，窄窗口会自动减小正文左右留白。
- 「外观设置」可分别修改字体颜色和背景颜色；点击色块打开系统颜色面板，点击对应吸管从屏幕取色，按 `Esc` 取消取色。
- 按 `⌘⇧B` 显示／隐藏窗口边框与阴影；也可从「阅读」菜单或外观设置切换。无边框时仍可按住顶部留白拖动窗口、拖动边缘缩放。
- 切换浅色／深色会恢复该主题的预设配色。
- `⌘O` 打开小说，`⌘＋` 增大字号，`⌘−` 减小字号，`⌘Q` 退出。
- 字号默认 20 pt，每次调整 2 pt，范围 12～40 pt。
- 菜单「窗口」的「进入／退出全屏」或 `⌃⌘F` 可切换全屏；「阅读」菜单也提供字号、主题和外观操作。关闭窗口后可通过「窗口」→「显示阅读窗口」或点击 Dock 图标重新显示。

应用自动保存字号、主题、自定义配色、边框开关、窗口位置与大小和每个文件的阅读位置。退出后重新打开会尝试重开上次文件，让上次阅读处重新出现在屏幕内。允许约一屏的向前回看误差。文件不存在时返回打开页面；授权失效时重新选择文件。正文由本地原文件读取，不修改小说文件。

## 构建

使用完整 Xcode 时，打开 `NovelReader.xcodeproj`，选择 `NovelReader` scheme 和 `My Mac`，编译运行。工程使用 Xcode 16 的目录同步格式及 Swift 6。默认采用本地 ad-hoc 签名；对外分发需要自行配置正式签名。

本机只有 Command Line Tools，因此另提供原生应用构建脚本。脚本使用已安装的 macOS 26.5 SDK，避开本机默认 SDK 缺失的 SwiftUI 宏插件；部署目标仍为 macOS 14。

```sh
zsh scripts/build.sh
open build/NovelReader.app
```

构建只使用系统 Swift、macOS SDK 和 `codesign`，不安装依赖。输出的应用是沙箱应用，仅具备用户选择文件的只读访问及持久书签权限，没有网络权限。

## 验证

```sh
zsh scripts/test.sh
zsh scripts/test.sh --benchmark 10
build/NovelReaderTests --benchmark 50
build/NovelReaderTests --benchmark 100
```

测试覆盖编码、字号与主题／自定义颜色／边框持久化、按文件保存位置、书签及重开、TextKit 2、滚动、远距离恢复、字号与窗口尺寸变化、无边框焦点、四角缩放计算和边缘命中，以及 SwiftUI 整页的启动恢复、窄窗口和顶部拖动区域。性能测试生成中文分段 TXT，产物和报告位于 `build`。

## 结构

`App` 为入口和菜单，`Views` 为页面，`Reader` 为 TextKit 阅读和进度协调，`Services` 为文件及本地存储，`Models` 为阅读状态，`Utilities` 为原生窗口配置。

正文整体读入内存，通过单个 NSTextView 按视口排版。阅读位置采用 UTF-16 文本偏移量，不以像素滚动距离作为持久记录。用户偏好与进度保存在应用沙箱的 `UserDefaults`，最近文件通过安全作用域书签访问。

本版仅支持 TXT。不提供书架、目录、搜索、书签、同步或其他阅读扩展功能。最新验证结果和环境限制见 `ROADMAP.md`。
